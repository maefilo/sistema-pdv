# Sistema PDV - Maê Filho

Sistema de PDV/Gerenciador de Confecção com gestão de produtos, pedidos e relatórios de vendas.

## Stack
- Frontend: React + TypeScript + Vite
- Backend: Express.js
- Banco: TiDB Cloud (schema: mae_filho)

## Deploy
- Frontend: Vercel
- Backend: Vercel/Render

## Configuração
Copie .env.example para .env e preencha as variáveis de ambiente.
